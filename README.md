# IC Calendar

Calendario di sola lettura, in italiano, per gli appelli del corso di laurea triennale in Ingegneria civile dell'Università di Bologna.

Il sito legge i dati aggiornati dalla [pagina ufficiale degli appelli](https://corsi.unibo.it/laurea/IngegneriaCivile/appelli) quando viene aperto o quando si preme **Aggiorna**. Gli intervalli mostrati hanno una durata indicativa di tre ore e servono esclusivamente a rendere visibili le sovrapposizioni.

## Funzioni

- viste mensile e settimanale;
- filtri per corso e docente;
- evidenza visiva degli appelli sovrapposti;
- esportazione CSV e iCalendar (`.ics`).

## Sviluppo locale

Il progetto non richiede dipendenze o compilazione. Servire la cartella `dist` con un server HTTP locale, quindi aprire l'indirizzo indicato dal server.

## Fonte e avvertenza

IC Calendar è un visualizzatore indipendente. In caso di discrepanze fanno fede esclusivamente i dati pubblicati dall'Università di Bologna.
